# Lodestar /03 — identity study

Generated29 October2026 using built-in `image_gen`, then one targeted edit to
correct both assembled views to six main bodies: head, four induction carriages,
tail. Selected `identity-v01.png` is copied byte-for-byte from generated output.
The original `identity-v00-draft.png` is retained as a superseded count study.
No CLI/API fallback or third-party artwork was used.

Exact original/refinement prompts, tool provenance and selected SHA256 are in
[identity-prompts.json](identity-prompts.json). This is a concept board for review,
not approved runtime parts or an atlas. Component dimensions, pivots and weapon
placement must be authored from the [full workshop plan](../../../../docs/LODESTAR_BOSS_WORKSHOP_PLAN.md).
Representative parts and broad bends convey identity; they do not certify actual
joint reach, game-camera resolution, collision or mechanical animation.

Review: the corrected hero and top view both show four copper-ring core carriages
between head and tail. Materials, attached crescents, couplers, roller support,
induction-pole idea and telescoping tail establish the proposed vocabulary.
Production will consolidate the pole equipment to the designated carriage and
use compatible orthographic parts, explicit sockets and constrained couplings.
