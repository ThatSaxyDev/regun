# Multiplayer wall kit

Generated with the built-in imagegen tool on 20 October 2026. Source: `wall_kit_master.png` (1448×1086 RGBA); packaged unchanged as `assets/art/arenas/multiplayer_walls.png`, SHA-256 `ae67899ef7b1b4e66e27baa469918fb048df94f900968aad7628d3b7c91885ff`. This is generated artwork, not a downloaded third-party atlas. Alpha component bounds (threshold 50, two-pixel padding) in `wall_frames.json` index the twelve separated pieces; no recoloring or pixel edits were applied. The atlas is decoded at 192px for regular arenas (108 KiB, retaining the existing 32 MiB shared-art limit even with active expansion encounters) and sampled without filtering.

Prompt: Production modular wall sprite atlas for Regun's dark crypt/industrial top-down shooter, twelve separated transparent sprites: horizontal/vertical crypt walls, corner post and island; horizontal/vertical riveted iron baffles, post and machine cover; stone L/T joins, end cap and cosmetic damaged wall. Charcoal green-grey stone, worn pale caps, oxidized iron, restrained brass, upper-left light; no text, characters, floor, neon or watermark. Simple readable solid footprints with intact bases and generous gutters. Detailed pixel-painted material matching the existing props.

The tool produced unequal sprite widths, so uniform grid slicing is deliberately avoided. The final renderer uses straight wall/baffle pieces for authoritative rectangles. Diagonal decorative islands/joins and the damaged variant are available in the kit preview, but are not substituted for rectangular collision truth. Cosmetic cracks never create a hole. `WallArt` preserves end caps, draws an exact solid-base outline, culls offscreen pieces and fades the upper art consistently around visible actors. `assets/tiles/multiplayer/*.tmx` owns placement; art never owns collision.

Online acquires a separate lazy 512px decode (`multiplayer_walls_hd.png`, same source bytes) for readable covered maps. It releases on route disposal. Only one survival boss is active online; regular Boss Rush never acquires this optional texture.
