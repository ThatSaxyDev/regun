# Airdrop support implementation and validation

25 October 2026. Implementation spans `regun`, sibling `regun-server` and
`regun-admin`. These are local working-tree changes, not a live rollout.
The current application identity remains the creator's `1.0.0+22`.

## Delivered behavior

- Supply hands draw support availability against an ordinary-only outcome of
  weight 1. Both default family weights 1 mean about two-thirds support hands
  (one support plus two ordinary cards), one-third three ordinary cards. One
  eligible default-weight family means a 50% support chance. Enablement never
  guarantees a card. Ordinary XP/fusion offers remain separate. Both families have temporary
  I–III tiers, per-family bans, bounded recent history and a single live/pending
  instance per owner. Tier III can be deployed again after expiry.
- Sentry calls follow the survivor until a legal location is committed, warn,
  descend, unfold and become stationary cover. Carbine and three-round burst use
  distinct original mounted gun sprites. The head turns toward one enemy and
  retains it despite nearer arrivals; a continuously unreachable target is
  replaced after the configured one-second fallback. Burst rounds are separate
  physical releases, with source-pinned ammunition, reload and distance damage.
- Landing and expiry each use one base friendly crush/blast/pressure receipt.
  Other cover applies, players take no damage, and cancellation never detonates.
  Support rounds respect directional ballistic defences without primary perks.
- Aura Farm follows its owner for a finite lifetime and damages body intersections
  on the shared tick. Cover applies, target count is bounded, and overlapping
  allied fields apply the strongest field once with deterministic ownership.
- Native pause/picker/entrance freeze support clocks. Continue restores phase,
  ammo, rounds, entitlement and impact receipts; malformed states are rejected.
  Co-op downing suspends support; revive resumes. Disconnect/bleed-out/end cleanup
  cancels it without replay or refund. The server owns choices, placement, rounds
  and hits; scoped reward requests validate room, generation and offer identity.
- Admin contains enable flags, weights and I–III values, linked weapon sources,
  local baseline/draft projections and authenticated API comparison. Catalogue
  generation archives the former contract; existing weapon defaults are retained.
- Training pause includes Sentry/Aura practice, which works while normal family
  flags are disabled. Boss Rush clears these deployments.

## Remaining release gates

Both normal family flags remain **Off** in the prepared catalogue, as required by
the approved plan. No live server/admin/web publication, remote enablement or
phone installation has been performed in this pass.

Pending: target-phone performance/texture/audio comparison, physical warning and
muzzle readability, control comfort, balance approval, hostile-warning overlap,
and the full integrated cover/crowd/boss/survivor matrix. Local browser interaction
was unavailable because browser use is disabled in Work settings; web compilation
is not represented as a browser playtest. Repeated randomized pure schedules and
local websocket tests do not establish flawless behavior on every device/network.

Roll out the new server/API and admin catalogue with flags Off, then compatible
clients (support capability 6). Validate disabled staging and enable each family
through the existing authenticated publication flow only after the remaining
acceptance checks. Existing runs/rooms retain pinned values. New enable flags can
stop future offers without hot-removing support from an active pinned run.

## Creator feedback correction: selection, firing and energy

The initial implementation's guaranteed support slot has been removed: Training and normal
supply receipts, including rerolls/bans and authoritative co-op hands, now use
weighted availability. Recent-family suppression affects the family draw, not the
chance of an ordinary-only hand. Explicit Training practice remains deliberate.

Sentry flight excludes its own emitting base from inflated wall geometry, while
retaining other cover. Close hits now leave a bounded 90–100ms trace of their
actual flight, so consuming a projectile before rendering cannot hide every
round. Analytic bounded target leading accounts for muzzle offset and uses a
cover-safe direct fallback. Gunfire still releases physical straight rounds;
tracking/reloading does not produce a fake shot. A reload label distinguishes
its downtime. Carbine and three-round burst remain separate.

Prepared sentry damage multipliers are 3/3.5/4 (previously 1/1.15/1.3), with admin
limits and shared projections refreshed. **Public production revision 5 was read
on 25 October and still has 1/1.15/1.3, with both families enabled.** A new client
alone does not replace that published tuning. The stronger values require a
compatible catalogue and a new admin publication; current runs retain pinned
values. No live configuration was modified during this correction.

Aura retains its authored ring/emitter and adds a chipped sixfold seal, sigils,
stepped branching currents and energized emitter tabs driven by active lifetime.
Reduced Motion holds a steady seal and emitters. It still only damages enemies:
no protection, damage reduction or healing was introduced.

Regression coverage includes seeded weighted-hand distributions (both and one
family), all 360 server emission headings against the original self-cover bug,
16 native close-contact headings for each mount, bounded moving-target leading,
actual clipped traces, animated normal frames and identical Reduced Motion frames.
Preview frames: `build/test-previews/aura-energy-frames/`.

Aura motion follow-up: outer ring rotates clockwise at .08 rad/s; inner seal
and its layered currents counterclockwise at .20 rad/s. Both use active life,
freeze on pause and hold steady under Reduced Motion. Shared native/online art.

Final correction verification: game analyzer clean; full game suite 736 passed,
five optional soak tests skipped; final affected runtime/visual suite 16 passed.
Server verify: 169 passed plus module build. Admin: analyzer clean, 60 tests,
release web build. API: 23 tests plus compiled smoke. Fresh game release web,
Android APK and unsigned iOS builds passed using the existing release defines.
Android remains private-test debug signed. No installation, deployment or live
admin publication was performed. The full suite ran before the final counter-
rotation and additional called-hand assertion; the final analyzer/focused suite
and all three client builds include those changes.
