# Airdrop support implementation and validation

25 October 2026. Implementation spans `regun`, sibling `regun-server` and
`regun-admin`. These are local working-tree changes, not a live rollout.
The current application identity remains the creator's `1.0.0+22`.

## Delivered behavior

- Supply hands draw support availability against an ordinary-only outcome of
  weight 2. Both default family weights 1 mean about half support hands
  (one support plus two ordinary cards), half three ordinary cards. One
  eligible default-weight family means a one-third support chance. Enablement never
  guarantees a card. Ordinary XP/fusion offers remain separate. Both families have temporary
  I–VIII tiers, per-family bans, bounded recent history and a single live/pending
  instance per owner. Tier VIII can be deployed again after expiry.
- Sentry calls follow the survivor until a legal location is committed, warn,
  descend, unfold and become stationary cover. Carbine and three-round burst use
  distinct original mounted gun sprites. The head turns toward one enemy and
  retains it despite nearer arrivals; a continuously unreachable target is
  replaced after the configured one-second fallback. Burst rounds are separate
  physical releases, with source-pinned ammunition, reload and distance damage.
- Landing and expiry each use one base friendly crush/blast/pressure receipt.
  Other cover applies, players take no damage, and cancellation never detonates.
  Support rounds respect directional ballistic defences without primary perks.
- Aura Salad follows its owner for a finite lifetime and damages body intersections
  on the shared tick. Cover applies, target count is bounded, and overlapping
  allied fields apply the strongest field once with deterministic ownership.
- Native pause/picker/entrance freeze support clocks. Continue restores phase,
  ammo, rounds, entitlement and impact receipts; malformed states are rejected.
  Co-op downing suspends support; revive resumes. Disconnect/bleed-out/end cleanup
  cancels it without replay or refund. The server owns choices, placement, rounds
  and hits; scoped reward requests validate room, generation and offer identity.
- Admin contains enable flags, weights and I–III values, linked weapon sources,
  local baseline/draft projections and authenticated API comparison. Catalogue
  generation archives the former contract; existing weapon defaults are retained.
- Training pause includes Sentry/Aura practice, which works while normal family
  flags are disabled. Boss Rush clears these deployments.
